# Additional Drop accessories

Nine unchanged Tripo ZIPs are pinned in `source-manifest.json`. Original delivery
names are retained there; `fit.json` gives the game/Blender names and fitted transforms.

| Slot | Item | Source |
| --- | --- | --- |
| Head | Starry Nightcap | item-01 |
| Body | Sailor Top | item-02 |
| Head | Seashell Hair | item-03 |
| Head | Sailor Hat | item-04 |
| Head | Navy Bandana | item-05 |
| Body | Mint Shirt | item-06 |
| Head | Explorer Helmet | item-07 |
| Head | Ribbon Boater | item-08 |
| Head | Sunshine Rain Hat | item-09 |

All nine are free, family-specific Wardrobe trial items, with isolated fixed icons.
Drop reuses its existing cream glasses. No Cosmetics tab is added to Shop.

The fitted geometry, repaired clothing, FBX handoff and game bake are documented
in [wardrobe-finish-v1](../wardrobe-finish-v1/README.md). The reference/before view
is produced from these actual meshes, not a generated illustration. To rebuild
raw inspection views: run Blender with `inspect-drop-extras-v1.py`, then Node with
`review-drop-extras-v1.mjs`.
