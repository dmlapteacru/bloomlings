Drop — комбинезон с футболкой, примерка к базовому герою

1. Открой свой основной Blender-проект с базой из cute+blue+character+3d+model (2).zip.
2. File > Import > FBX: выбери Drop_Overalls_Fitted.fbx.
3. Оставь Import Scale = 1.0. Не центрируй и не масштабируй одежду отдельно.
4. В файле только одежда: один объект Drop_Overalls_Fitted. Лица, тела и конечностей донора в нём нет.
5. Текстура встроена в FBX. UV-развёртка одежды сохранена.

Preview_FullCharacter.glb — только для просмотра всей примерки. Он содержит копию базы;
не импортируй его поверх своей базы, если не хочешь получить дубликаты.
Before_After.png: слева база, в центре исходная одежда на той же базе, справа результат подгонки.

Геометрия и пропорции базового героя не изменены. Одежда укорочена примерно на 20%,
подогнана по ширине и поверхности тела. Обратный импорт FBX проверен в Blender.

Это примерка в исходной позе. У присланных моделей нет скелета и весов;
проверку сгибания рукавов и штанин нужно делать с ригом твоей общей базы.
Исходные края сегментации Tripo сохранены; новая ретопология здесь не выполнялась.
