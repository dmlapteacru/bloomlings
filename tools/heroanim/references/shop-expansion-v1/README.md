# Новая партия вещей — референсы для моделирования

44 вещи: **по 7 Head (5 общих типов + 2 индивидуальных), 2 Face и 2 Body на героя**.
8 листов: у каждого героя отдельный лист голов и отдельный лист лица/одежды.
Это новые варианты в дополнение к уже существующим кепкам, панамам, беретам и сезонным комплектам.

## Для Tripo / Blender

- Для генерации одной вещи используй одну соответствующую ячейку, не весь лист.
- База из твоего мастер-файла Blender остаётся эталоном размеров головы и тела. Рисунки задают форму вещи, не заменяют эту базу.
- Одежда тонкая, короткая, без утолщения тела. При сегментации выделяй одежду отдельно; новые тело/руки от AI не должны подменять исходного героя.
- Причёска и убор — один Head. У Bloom под уборами остаются короткие лепестковые пряди; у Drop уборы на округлой базе, без высокой капли под ними.
- Face остаётся независимым от Head. Линзы без нарисованных глаз, окружения и отражений. При проблемах генерации делай пустую оправу: линзы добавим отдельной простой геометрией при интеграции.
- Лысые BASE и лысые герои в одежде — только подложки для моделирования. В игре голова всегда с дефолтным Head или выбранным убором.

Набор не меняет игровой каталог, цены, сохранения, риги и runtime-ассеты. Модели добавляются после получения файлов от владельца.
