# Sprig modular modeling baseline

[base-full-front.png](base-full-front.png) is the requested bald Sprig base for Tripo / Meshy generation: approved
face / lime palette / short body, relaxed symmetric arms, with the leaf hairstyle removed. It is an offline modeling
reference. The owner has now supplied the fitted SprigHeroV2 model and items; see
[the source and rebuild guide](../../models/sprig-v2/README.md) for the current in-game preview.

[with-default-leaves-front.png](with-default-leaves-front.png) preserves the currently approved Sprig appearance.
The final game hero needs a default leafy head style; the bald base is for modeling / interchangeable head parts.
`manifest.json` pins both reference images. Neither enters application resources.

[heads-three-hairstyles.png](heads-three-hairstyles.png) shows the requested three headwear concepts on the common base: 1 soft rounded leaf cap with short forelock, 2 compact side-part leaf crop, 3 curled leaf forelock. They are front-view modeling references; no new mesh or game replacement is included.

The owner replaced the first tall crest with a softer, cuter rounded leaf cap. The earlier crest is retained in Git history.

[SET.md](SET.md) lists the complete requested modular set: three existing hair concepts, five additional Head variants, one scarf, three seasonal Clothes variants and the reused round glasses mesh (material adjustment later). New standalone generation references are under `set/`.
