# Retired Twig runtime art

The owner approved TwigHeroV2 permanently on 2026-10-17 after testing it in game. These 263 former PNG resources
(11,631,125 bytes), four generated / helper C# files and bake records are preserved for history only. Nothing in this
folder is compiled or packaged. Active source and references: `../../models/twig-v2/` and `../../references/twig-v2/`.

`manifest.json` pins the retired PNG bytes; `motion-manifest.json` preserves the retired Twig entries from the previous motion library.
Historical metadata records the recipe at retirement; paths in it refer to the former runtime locations and are not
current rebuild instructions. Earlier model delivery archives remain in their historical `models/` directories.
Retired publisher entry points require `--review` and cannot overwrite production assets.

The new Twig uses its own supplied rig / accessory sources and retains static poses plus existing 2D breathing until
the separately planned action feature. Saved item IDs remain compatible; the old flower cap maps to the new Panama.
