BLOOMLINGS · ИГРОВОЙ ТЕСТ

Новые картинки · итерация 8E

Все 30 картинок нарисованы заново: 16 цветов, по четыре на героя, новые вводятся по одному с L6 до L13. Поля разные: сложные большие, между ними маленькие передышки и картинки «только предмет». Поле обнесено забором с воротами: муравьи заходят через ворота и по дорожке обходят картинку, поэтому могут есть её с разных сторон. В очереди видно три ряда, глубже ничего не видно. Связки и капсулы ? в основном на сложных уровнях, у каждого Super Hard своя особенность. Когда очередь закончилась, работа идёт на ×2,5.

Команды продолжают работать, пока ты выбираешь следующие. С самого начала — цветные рисунки и пять мест. Число на капсуле — сколько героев ещё выйдет. Когда вся команда отправилась, место освобождается; герои продолжают собирать клетки. Внешний вид этого теста временный; принятый UI игры сохраняем отдельно.

  1. Можно отправить несколько верхних капсул подряд, пока на экране есть пустые места.
  2. Команда собирает только точный материал своей капсулы.
  3. Пока работа недоступна, остаток занимает место. Для пары нужны 2 места; оба освободятся только после завершения всей пары.

Капсулы ? — L6, L10, L19, L25, L30. Одноцветная пара — L8, смешанная — L9, первый Super Hard — L10, мостик — L20. Когда очередь закончится, автоматически включится ×3.

Прогресс и результаты сохраняются в этом браузере. Их можно скачать файлом; автоматической отправки нет.
