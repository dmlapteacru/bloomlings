## Что сохранить

- **L10**: шесть попыток, включая один прерванный повтор, «трудно / интересно». Владелец особо отметил решение отправить только один розовый лот, чтобы тот завершился, вместо параллельного запуска двух. Это положительный сигнал для механики разделения доступной работы между одинаковыми цветами. Нельзя автоматически исправлять такую конкуренцию как нежелательную задержку.
- **L22**: «трудно / интересно», прямое «оставляем». Знакомство с задачей уже влияет на прохождение.
- **L20 и L29**: «интересно». Мостики сохраняют смысл; новый проход не даёт причины заменять их целиком.
- Все оценки темпа «хорошо». Не менять глобальную скорость одновременно с цветами и скрытыми лотами.
- L1–9 узнаются. У новой первой девятки остаётся девять побед с первой попытки, но четыре уровня оценены «нормально», а L5/6/7/9 потребовали планирования по самооценке. Без нового независимого игрока это не оценка обучения новичка.

## Что переработать

- **L8/16/23/26/28**: «скучно». L8 занимает 111 с и всё равно скучен; L16 — 23 с. Ни удлинение, ни сокращение сами по себе не исправляют задачу.
- **L15**: единственный «картинка не узнаётся» и прямое замечание, что торт можно заменить любым другим сюжетом. Предлагается пчёлка с крупными полосами после появления жёлтого материала, а не детализация текущего торта.
- **L17**: формальная оценка изображения «да», но в заметке лейка похожа на чайник. Нужны длинный наклонный носик с душевой насадкой и явный верхний проём; не считать эту картинку полностью решённой.
- **L25**: владелец хочет сложнее и больше неизвестности. Этот уровень кандидат для сочетания скрытого лота и связки; L10/L22 лучше оставить контрольными.

## Почему неизвестность почти не чувствуется

Текущая механика — **скрытая глубина очереди**. Как только лот оказывается верхним, цвет раскрывается до выбора. Это явно реализовано в `Timeline.commit`, а UI запрещает выбираемый нераскрытый верх. Во всех 16 отправках бывших скрытых лотов в победах цвет уже был известен.

Лоты `?` есть только на **L6/7/12/14/17/19/26/30**, по два на уровень. **Ни один Hard их не содержит.** Все эти уровни пройдены с первой попытки; ни один не получил «интересно», L26 — «скучно / тапал всё подряд».

| Уровень | Доля работы двух `?` | Очищено поля при раскрытии первого / второго |
| --- | ---: | ---: |
| 6 | 3,8% | 0% / 46% |
| 7 | 4,2% | 0% / 10% |
| 12 | 2,5% | 0% / 21% |
| 14 | 3,3% | 24% / 63% |
| 17 | 3,3% | 0% / 0% |
| 19 | 1,9% | 15% / 56% |
| 26 | 2,4% | 27% / 35% |
| 30 | 6,9% | 0% / 42% |

Следовательно, дело **не только в позднем появлении**: на L17 оба раскрылись ещё до очистки первой клетки. Но раскрытие не обязательно требует содержательного решения. На части уровней оно происходит и при полном ряду; сам факт нехватки места тоже не доказывает, что неизвестность влияет на стратегию.

Авторинг ограничивает домен двумя равными небольшими лотами разных цветов; проверка рассматривает две перестановки. Неизвестность быстро исчерпывается. Для значимой механики нужно проектировать цену раскрытия/резерв места и последствия разных цветов, а не просто добавлять больше значков `?` в хвост очереди.

## Границы анализа

В отчёте отдельно сохранены оценки и заметки каждой попытки. Точный проигрыш воспроизведён, но «первый необратимый ход» не вычислялся: для живой модели время ввода имеет значение, старый статический решатель не доказывает необратимость. `logicalOutcome` в исходном экспорте — устаревшее поле, часто остающееся `playing`; проверка использует настоящий воспроизведённый терминальный исход. Изменений игрового v7 этим разбором не вносится.
