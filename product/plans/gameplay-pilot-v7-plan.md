# Pilot v7 — узнаваемые первые картинки

## Цель

Проверить, лучше ли читаются ранние рисунки на телефоне. Это итерация контента поверх **той же событийной модели v6**, а не новое изменение скорости или правил. Без переноса в Unity и без пересборки каталога 2500 уровней.

## Что перерисовано

| Уровень | Характерные детали |
| --- | --- |
| 1, лист | Заострённый силуэт, черешок, непрерывная центральная жилка и боковые жилки на родной сетке |
| 2, капля | Цельный голубой силуэт с выраженной вершиной, округлым низом и маленьким лицом; убран цветок поверх капли |
| 3, цветок | Шесть отдельных крупных лепестков, светлая сердцевина, два листа |
| 4, бабочка | Разделённые верхние и нижние крылья, узкое тело, усики, симметричные крупные пятна |
| 5, жёлудь | Широкая чашечка, крупный орех с заострённым концом, веточка и лист; розовый материал вынесен в маленький опавший цветок |
| 6, гриб | Светлые пятна на шляпке и светлая толстая ножка вместо голубых пятен и коричневого столбика |
| 7, клубника | Сердцевидная ягода, зелёная чашечка, светлые семечки вместо коричневых пятен |
| 8, чашка | Просвет в ручке, округлый низ, цветочный рисунок, пар |
| 9, письмо | Крупный клапан конверта, диагональные сгибы, сердечко-печать |

Рисунки описаны прямо на игровых сетках, а не получены уменьшением детальной иллюстрации. Размеры сохранены: 16×18, 18×20, 20×22, затем 24×26 до L9. Общая палитра и порядок знакомства с материалами прежние. Не добавляем близкие оттенки ради декоративной детализации.

В L6–7 теперь используется уже знакомый кремовый материал для пятен и семечек; в L8 добавлен зелёный материал блюдца. Поэтому набор материалов внутри отдельного рисунка может измениться, хотя момент первого знакомства с каждым материалом не меняется.

**L10–30 сохранены полностью**, включая очереди, скрытые лоты и мостики. Понравившиеся L10/15/21/22/25/29 остаются контрольными задачами. В L1–9 изменение формы меняет количество и доступность клеток, поэтому очереди пересобраны и проверены заново. Число лотов и моменты появления механик сохранены. Сложность ранних уровней может отличаться: это не чистое сравнение двух обложек одной задачи.

## Правила и скорость

`timeline.cjs`, `rules.cjs`, `palette.cjs`, `clock.cjs` побайтово равны v6. Интервал выходов 250 мс; путь 100 мс/клетку туда и 75 мс обратно при 1×; освобождение места через 300 мс после последнего выхода команды. Пары, параллельная работа одинаковых цветов, автоматический ×2 и паузы не менялись.

Новая отдельная версия сохранений/экспорта — `bloomlings-pilot-results-7`. Сохранения v6 не смешиваются с новыми очередями. События и время принятых команд продолжают записываться для точного воспроизведения.

## Проверка и отзыв

Проверяем суммы материала, реальные победные маршруты всех 30 уровней, информационную стратегию двух допустимых скрытых перестановок, параллельные вводы, восстановление, мобильную раскладку и экспорт в браузере. Автоматические политики используются только для отбора очередей; их доли побед не являются прогнозом сложности для человека.

При тесте особенно важна оценка «Картинка узнаётся?» на L1–9. Название видно в интерфейсе, поэтому эта оценка сама по себе не является слепым тестом узнаваемости. Полезно сначала посмотреть на силуэт, не читая заголовок. Первое прохождение — на 1×; по завершении скачать JSON результатов.
