# Wardrobe — варианты компоновки

Дизайн-концепты, созданные по текущему экрану и принятой базе Sprig. Игровая реализация в этой задаче не меняется.

## Что мешает сейчас

Большая арка оставляет герою небольшую часть стенда. У каждого элемента каталога повторяются маленький герой, подиум, табличка и широкая деревянная полка. В трёх колонках изображение самой вещи занимает мало места.

## A — рекомендуемый

Один неглубокий каменный стенд без арки; герой занимает большую часть примерочной. Две существующие строки фильтров остаются между примерочной и каталогом. Ниже — две колонки крупных карточек вещей, приблизительно четыре видимых элемента на длинном телефоне. Толстых полок и повторных подиумов нет. Одна строка названия и компактная цена/статус встроены в карточку. Примерочная, фильтры и нижняя навигация закреплены; прокручивается только каталог.

## B — выдвижной каталог

Больше места герою, в обычном виде один крупный ряд вещей. Панель можно поднять и получить больше рядов; при этом видимая область примерочной уменьшается. Оба существующих фильтра остаются на панели. Требуется дополнительный жест и два устойчивых положения панели, поэтому A проще для постоянного выбора вещей.

## Общие правила

- Сохранить обе строки фильтров, текущие материалы кнопок и нижнюю навигацию с непрозрачной задней стенкой.
- Меняется только основной герой при примерке. Карточки показывают своё неизменное изображение вещи, независимо от надетого комплекта.
- Для Face показывать крупную оправу, для Head — убор/причёску, для Body — одежду; не повторять целого маленького героя в каждой карточке.
- На низких экранах показывать меньше рядов, сохраняя крупные карточки. Продолжение доступно обычным вертикальным свайпом.
- Названия, цены и вещи на концептах иллюстрируют компоновку; они не меняют каталог, цены или сохранения.

Файлы: `source-current.png` — реальный исходный экран; `A-fixed-two-column.png` и `B-expandable-catalogue.png` — сгенерированные визуальные концепты.

## A3 — сетка 3×3

По просьбе владельца: тот же крупный герой, стенд и фильтры, каталог из трёх колонок и трёх видимых рядов. Карточки показывают только вещи, поэтому девять вариантов можно сравнивать без маленьких героев и полок. Файл: `A3-fixed-three-column.png`. Это дополнительный концепт для выбора, не изменение игры.
