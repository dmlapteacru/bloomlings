# Shop secondary navigation: concept exploration

Created 2026-10-13 with built-in OpenAI ImageGen, using `source-shop.png` as the edit target. These are AI visual concepts for choosing a navigation approach, not screenshots of an implemented change. No new navigation assets or runtime behavior are shipped by this iteration. The earlier v3 shape experiment was discarded after the owner requested a new approach.

Source: shared Skia Shop preview, 1080x2340, with the same existing body, background, title, balance and bottom menu. Generated edits are copied unchanged; fine details outside the requested navigation row may differ slightly due to raster regeneration.

- `01-cream-segments.png`: one cream segmented navigation component.
- `02-wood-tabs.png`: small wooden nameplates, green selected rim.
- `03-folder-tabs.png`: raised active folder tab on a shared cream ledge.

Only after selection will separate production assets be generated and the chosen approach implemented.
