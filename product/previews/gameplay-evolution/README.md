# Визуальный план Bloomlings

Откройте [index.html](index.html) в браузере. Это один автономный файл: герои, фон, шрифты, иллюстрации и полный текст плана включены внутрь. Для просмотра не нужны интернет, npm или сервер. На телефоне важно открыть файл браузером: предварительный просмотр вложений может не выполнять JavaScript.

На странице:

- Девять разных эскизов этапов L1 / 4 / 7 / 12 / 20 / 25 / 40 / 75 / 100 с точными размерами сеток и фактическим числом нарисованных клеток.
- Переключение символов и сетки; весь предлагаемый рост L1–25.
- Команды четырёх принятых героев и расширение палитры.
- Интерактивные схемы мостика Sprig и обмена равных цветовых групп Bloom. Можно менять порядок запуска капсулы и действия героя, видеть остаток и занятый слот.
- Приоритеты, сохранённые продуктовые решения и полный Markdown-план с таблицами. Кнопки скачивания текста и печати/PDF.

Эскизы не входят в каталог игры и не являются сертифицированными уровнями. Капсулы первого экрана — примеры отображения, а не рассчитанная очередь. Действия героев пока предлагаются для обсуждения; в первый прототип рекомендован только мостик Sprig. Мозаика Twig L2000 не изменена.

Быстрый просмотр без интерактивности: [PDF для чтения на телефоне](reading.pdf), [девять эскизов](examples.png) и [пример L20](level20.png).

Проверено в Chromium на ширинах 320 / 360 / 390 / 430 / 768 / 1280: все девять этапов и раскрытый полный план без горизонтального переполнения страницы. Проверены оба порядка действий в обеих схемах, сброс, переключатели, клавиатурная навигация, область основных кнопок не менее 44 пикселей, уменьшение анимации, загрузка всех изображений и скачивание точного текста плана. Внешних запросов и ошибок JavaScript нет. Это проверка веб-превью, не игровых уровней и не конкретного устройства Safari.

Исходники: [tools/gameplay-preview](../../../tools/gameplay-preview). Пересобрать после изменения [плана](../../plans/gameplay-evolution-v2.md):

```sh
python3 tools/gameplay-preview/build.py
```

Сборка использует только стандартную библиотеку Python и существующие ассеты репозитория. Она не меняет изображения героев, игровой код и данные уровней.

Снимки и PDF — экспорт той же страницы. Для обновления после сборки HTML, если уже доступны зависимости `tools/heroanim` и Chromium:

```sh
node tools/gameplay-preview/render.mjs
```

Можно указать путь браузера в `BLOOMLINGS_CHROMIUM`. Самому пользователю для открытия готовых HTML/PDF эти зависимости не нужны.
