# Bloomlings v8E — картинки (в работе)

Уровней v8E пока нет: сначала картинки, по просьбе владельца («перерисуй и покажи сначала»).

- [`art-all.png`](art-all.png) — все 30 картинок v8E.
- [`art-proof.png`](art-proof.png) — первая проба на 4 уровнях рядом с v8D и тортом Colony Flow L20.

## Что решено (владелец, 23.10)

- **Цвета:** 16, по 4 на героя.
  - Sprig: лист, солнце, лайм, мох.
  - Bloom: лепесток, слива, ягода, румянец.
  - Drop: вода, жемчуг, глубина, небо.
  - Twig: янтарь, земля, тыква, кора.
- **Поле не растёт сплошняком** (владелец, 23.10, по Colony Flow: в их первых 30 уровнях поля от 18×21 до 38×28, есть вытянутые).
  - Сложные уровни большие: Hard 32×34, Super Hard 34×36.
  - Между ними встречаются маленькие передышки: 18×22, 20×22, 20×20, 22×22.
  - Есть вытянутые поля: 24×28, 28×26, 32×28.
- **Картинки «только предмет», без фона** — 7 из 30: L3, L5, L7, L16, L23, L28, L30. Поле обрезано по предмету, вокруг одна клетка открытой земли. У Colony Flow так нарисована почти половина обычных уровней в первых 30, дальше около 5%.
- **Длина раунда (цель):** обычный 1–1,5 мин, Hard ~2,5 мин, Super Hard 3,5–4 мин.
- **×2:** платный, как у Colony Flow.
- **Картинки:**
  - предмет занимает большую часть поля;
  - ровный контур в одну клетку;
  - объём в тонах того же героя;
  - фон — тоже работа, с узором (скатерть, обои, доски, ночное небо, вода).

## Как устроено

- **Палитра:** `tools/gameplay-pilot-v8e/palette.cjs`.
- **Отрисовщик:** `draw.mjs`. Гладкие фигуры переводятся в клетки поля нужного размера.
- **Сцены:** `scenes.mjs`.
- **Новые цвета вводятся по одному:** Небо на L6, Ягода на L7, Мох на L8, Румянец на L9, Глубина на L10, Лайм на L12, Кора на L13. На каждом уровне картинка берёт только уже знакомые цвета.
- **Мостик:** у уровней с мостиком (L20, L21, L22, L24, L29) сохранён ручей из v8 — стена поперёк поля, перегородка над ней, место для мостика.
