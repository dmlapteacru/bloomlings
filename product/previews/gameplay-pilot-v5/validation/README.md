# Проверки финальной v5

- `javascript.json` / `native.txt`: 381 сценарий, 4249 принятых действий, 54 мостика через JavaScript и настоящий C# Core. Все 30 задач решаемы; 22 определения совпадают с v4 целиком, включая шесть интересных контролей. На пяти Hard проверены 10 разнесённых полезных проигрышных альтернатив. На шести новых Normal проверены отложенные ошибки, на пяти из них ошибочный ход сразу снимает клетки. Все первые ходы L5 допускают победу. Скрытые допустимые миры проверены без оракула. Unknown не объявляется поражением.
- `timeline.json`: 60 полных прогонов, 1293 сохранения/восстановления, 22014 проверок маршрутов. Живой физический фронт, отсутствие двойных назначений/расхода квоты, резерв при выходе, узкий проход, несколько команд одного материала, совместное удержание пары, возвраты перед освобождением/победой, мост при полном ряду. Допустимые цели не простаивают при готовом интервале выхода. Наблюдалось до 73 одновременных курьеров, до 23 от одной капсулы; это наблюдения, не лимиты. Проверены 1×/2× и разное разбиение на кадры.
- `compatibility.json`: 40 исходных последовательностей владельца на неизменённых уровнях: 22 победы и 18 поражений сохраняют исход. При необходимости вставляется ожидание физического места; времена v4 не переносятся на новую модель.
- `clock.json`: переход учитывает прошлое состояние активности; скрытая/меню-пауза исключается, перезагрузка стартует с остановленных часов, обратный ход времени отклоняется.
- `lifecycle.json`: через реальные DOM-обработчики проверены 30 с меню и 60 с эмулированной скрытой вкладки без начисления времени/движения, возобновление, reload посреди потока с сохранением назначений и резервов, начальная скорость и реальные события. Видимость эмулируется через `document.hidden` и `visibilitychange`; это не замер поведения настоящего фонового мобильного браузера.
- `browser.json`: финальный HTML, все 30 пройдены через DOM, 61 проверка раскладки на 320/360/390/430/768/1280, отдельный реальный touch во время работы. Проверены пара, сохранение, быстрые тапы, обе палитры, пауза, ретрай, ручная/автоскорость и скачивание результатов; ошибок JS и внешних запросов нет.
- `export.json`: у каждого назначения завершённых попыток есть ровно один выход/прибытие/снятие/возврат, фактические времена совпадают с маршрутом при запуске; освобождение после возвратов всей группы, положительный физический фронт. Суммы временных категорий совпадают. Это искусственный QA-проход, не человеческий тест.
- `artifacts.json`: хеши финального HTML/ZIP, проверка ZIP и идентичность HTML внутри архива; v4 не изменена. Все ресурсы встроены. Облачный Chromium ранее запрещал прямые `file://` политикой; финальный файл проверен по локальному HTTP без внешних запросов. Открытие на реальном телефоне ещё проверяет владелец.

Сложность для новичка, узнаваемость двух новых силуэтов, удовольствие и доля ожидания ждут ручного прохода. Пилот не установлен в Unity или релизные 2500 уровней.
