# Проверки v4

- `javascript.json`: все 30 решаемы; 375 сценариев, 4318 принятых действий, 10 доказанных разнесённых проигрышных ветвей на пяти Hard; 8 информационных политик, 4 непустых выбора берега. Unknown не принимается за поражение.
- `native.txt`: те же сценарии и сигнатуры через настоящий C# Core, включая 51 действие мостика. В тестовом адаптере явно заданы пять мест, раскрытие верха и общий резерв пары. Клиент Unity не изменён.
- `timeline.json`: 60 полных временных прогонов, 1265 восстановлений; проверены физическая готовность пути, ограничения курьеров, возврат перед освобождением, пары, мост, 1×/2× и разбиение времени на кадры. Времена в таблице — автоматические эталонные маршруты, не ручной плейтест.
- `browser.json`: прогон финального автономного HTML в Chromium по HTTP без внешних запросов; все 30 пройдены через DOM, 61 проверка раскладки на ширинах 320/360/390/430/768/1280, отдельный реальный touch-ввод во время работы. Проверены пауза, восстановление рейсов/пары, скрытая глубина, две палитры, ретрай и скачивание JSON.
- `artifacts.json`: хеши итогового HTML и ZIP, проверка ZIP, идентичность HTML внутри архива; исходная v3 не изменена.
- `offline.json`: статическая проверка встроенных ресурсов; прямое открытие `file://` запрещено политикой облачного Chromium (`ERR_BLOCKED_BY_ADMINISTRATOR`). Политика не обходилась. HTTP-прогон проверяет тот же файл без внешних зависимостей. Открытие на реальном телефоне остаётся ручной проверкой.

Это результаты машинных проверок. Сложность для человека, удовольствие, различимость на реальном экране и допустимая доля ожидания ещё не подтверждены. Приложенный каталог не установлен в релизные 2500 уровней.
