# Bloomlings — L1–30, итерация 3

Открыть [index.html](index.html) в браузере. Это один автономный HTML: без установки, APK и подключения к интернету. Все уровни доступны через кнопку слева сверху. После теста: выбор уровней → «Результаты и заметки» → скачать JSON.

Итерация по [50 попыткам владельца в v2](../../playtests/pilot-v2-owner-2026-10-19/README.md) и [согласованному плану](../../plans/gameplay-pilot-v3-plan.md). Сыгранные v1/v2, основной клиент, каталог L1–2500, риги и принятая [визуальная база игры](../../design/visual-identity.md) сохранены. HTML проверяет геймплей; оформление остаётся прототипом.

## Что изменилось

- **Можно выбирать следующую капсулу во время работы предыдущих**, если на экране есть свободные места. Работа идёт по реальным событиям очистки, а не по декоративному таймеру блокировки. Временно заполненный ряд с работающими командами ещё не означает проигрыш. Итог появляется после остановки работы; доступный мост может спасти заполненный ряд.
- **L1–9: 3 места по умолчанию; можно сравнить с 4.** Переключатель находится в выборе уровней. Поле, очередь и скорость одинаковые; для каждой ёмкости отдельная сохраняемая попытка. L10–30 сохраняют пять мест. Это эксперимент, а не финальное решение об открытии дополнительных мест.
- Ранние очереди переработаны. В L5/L7/L9 выигрышный маршрут включает подготовительный ход: команда сначала ждёт, другой цвет открывает к ней путь. Это простые обучающие зависимости, не обещание сложности Hard. Одно уменьшение количества мест не считается достаточным улучшением.
- **Верхняя капсула всегда раскрыта до выбора.** Неизвестность остаётся в глубине очереди; новый верх открывается сразу после одиночного или парного выбора, даже пока предыдущая команда работает. При ретрае содержимое не меняется.
- **L15 и L22 сохранены**, вместе с ещё 16 контрольными уровнями. У них не менялись поля, капсулы, очередь, входы и мосты. Общее новое управление и раскрытие верха применяются ко всей партии.
- Перерисованы **L17 — садовый сапог, L25 — котёнок, L26 — подсолнух**. После изменения геометрии их очереди сгенерированы и проверены заново. L25 сохраняет критерии Hard, но это уже другая конкретная задача.
- Оценки **сложности и интереса разделены**. Сохраняются также узнаваемость, необходимость продумывать очередь и заметка.

Сохранены: старт 16×18, минимум 9 капсул / 8 самостоятельных выборов, знакомство с героями через материалы, пары с L10, первый Hard L15, мостик L18, выбор берега L19. Hard: L15/L22/L25/L29. Оба места пары заняты до завершения всей пары; готовая половина показывает ✓. Ретрай бесплатный. **Авто×2 включается при исчерпании очереди**, а не от заполнения мест. Ручное ускорение меняет только скорость работы. Уменьшение движения в настройках браузера отключает покачивание, но сохраняет темп очистки и правила мест.

## Что проверять вручную

Пройти L1–30 по умолчанию; при желании сравнить несколько ранних задач с четырьмя местами. Интересуют подготовительные действия до L10, ощущение заполнения мест, удобство быстрых тапов, сравнение с сохранёнными L15/L22 и узнаваемость трёх новых рисунков. Не требуется непременно проигрывать чаще: важны понятные последствия выбора и желание повторить.

Результаты сохраняются локально в отдельном пространстве v3. Экспорт `Bloomlings-pilot-v3-results-….json` содержит ёмкость каждой попытки, принятые команды, время принятых и отклонённых нажатий с причиной, логическую и визуальную занятость, остаток работы, освобождение мест, завершение и включение ×2. Автоматической отправки нет. Незаконченная визуальная работа сохраняется локально и восстанавливается при повторном открытии HTML в том же браузере.

## Данные и воспроизведение проверок

[levels.json](../../../content/pilot-v3/levels.json) — только задачи. [certificates.json](../../../content/pilot-v3/certificates.json) — выигрышные маршруты для 39 конфигураций, информационные стратегии, ошибочные ветви и мосты. Решения **не включены** в игровой HTML. [quality.json](../../../content/pilot-v3/quality.json) — авторские диагностические метрики; проценты ботов не являются вероятностью победы человека. [Все картинки](art-contact.png), [результат проверок](validation.json).

```bash
node tools/gameplay-pilot-v3/verify.mjs
node tools/gameplay-pilot-v3/timeline-check.mjs
dotnet build tools/gameplay-pilot-v3/check/Bloomlings.Pilot.V3.Check.csproj --artifacts-path /tmp/bloomlings-pilot-v3-dotnet
dotnet /tmp/bloomlings-pilot-v3-dotnet/bin/Bloomlings.Pilot.V3.Check/debug/Bloomlings.Pilot.V3.Check.dll /tmp/bloomlings-pilot-v3-verification/transcripts.json
python3 tools/gameplay-pilot-v3/build.py
python3 tools/gameplay-pilot-v3/contact-sheet.py
node tools/gameplay-pilot-v3/browser-check.mjs
```

Проверочный C# проект использует настоящее ядро очистки. Экспериментальные ёмкость 3/4, раскрытие нового верха, совместное резервирование пары, мост и итоговый статус задаются явными адаптерами. Эти проверки не означают, что отличия уже установлены в релизный Core. Временная модель отдельно проверяет серии тапов, сохранение посреди работы, завершённую половину пары, видимую готовность моста, разбиение времени на кадры и ×2. Браузерная проверка нажимает настоящие DOM-кнопки; ускоренные проходы используют часы браузера, отдельный тест — обычное время и touch-ввод.

Для повторного авторинга: `node tools/gameplay-pilot-v3/generate.mjs --out=/tmp/pilot-v3-rebuild`. Можно выбрать `--only=26`. Генератор сохраняет контрольные задачи v2 и перерабатывает только L1–9/L17/L25/L26; ничего не устанавливает в клиент. Изменённый хеш создаёт новое пространство сохранений.

Человеческую трудность, интерес и узнаваемость проверит следующий плейтест. Автоматические проверки подтверждают корректность и допустимые маршруты, а не удовольствие от игры. Производительность Unity/APK на устройстве этим тестом не измеряется.
