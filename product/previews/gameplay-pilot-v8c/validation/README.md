# Проверки v8C

- **`engine.json`** (`verify.mjs`):
  - 50 победных маршрутов (30 уровней и 20 скрытых вариантов);
  - 10 общих стратегий до раскрытия;
  - 240 прогонов с параллельными нажатиями;
  - `botGates` — коридоры ролей на всех уровнях с L5 (контроли L10, L22, L29 только воспроизводятся).
- **`controls.json`:** реальные попытки владельца из v7 на неизменённых контрольных уровнях воспроизводятся так же.
- **`browser.json`:**
  - все 30 уровней пройдены через DOM автономного HTML;
  - 36 раскладок экрана;
  - 20 раскрытий скрытых капсул при подъёме наверх (верхняя капсула никогда не скрыта);
  - сохранение после перезагрузки;
  - скачивание и воспроизведение отчёта.
- **`clock.json`, `lifecycle.json`, `storage.json`:** часы на паузе, поток после перезагрузки, полное сохранение сессии.

Проверки запускались в облачной сессии 2026-10-21 с Chromium Playwright `/opt/pw-browsers/chromium-1194`, подставленным вместо `/usr/bin/chromium`.

Метрики ботов — диагностика, а не доля побед людей. APK, Unity и производственный каталог не менялись.
