# Bloomlings v8C — роли уровней и раскрытие «?» наверху

Открыть `index.html` в браузере телефона. Всё встроено, сеть не нужна. Сохранение отдельное от v8. Начать с 1×, все уровни доступны через меню. После теста скачать JSON через результаты: файл `Bloomlings-pilot-v8C-results-*.json`.

«C» — вариант, собранный по [прогону ботов v8](../../audits/pilot-v8-bots-2026-10-21.md) и договорённости с владельцем от 21–22 октября. Скорость, размеры полей, входы и мостики те же, что в v8.

## Что изменилось относительно v8

1. **Скрытая капсула раскрывается, когда становится верхней в колонке, ещё до выбора.** Так в Colony Flow: это видно на записи их L10. «Закрытые» капсулы v8, которые раскрывались только после отправки, переведены в этот режим. Подсказки в игре переписаны, сообщение «Открыто: цвет · число» появляется в момент подъёма наверх.
2. **У каждого уровня с L5 есть роль и коридор сложности по ботам.** Уровень из v8 оставлен, если уже попадает в свой коридор. Иначе капсулы разбиты и расставлены заново на той же картинке или на новой сцене.
3. **Шесть новых сцен** (L6, L8, L11, L13, L16, L28): облака, солнце, трава, пруд, холм, стол, дождь. Цвета частично лежат и снаружи, и внутри, поэтому капсула доедает внешнюю часть и ждёт внутреннюю. Сравнение: [`art-before-after.png`](art-before-after.png), все уровни: [`art-contact.png`](art-contact.png).
4. **Метка Super Hard** у контрольных L10, L22 и L29. Интерфейс показывает её красным, а Hard — как раньше.

## Роли и коридоры

Обозначения:
- «Случайные тапы» — бот тапает любую доступную верхнюю капсулу;
- «Видимый цвет» — бот тапает случайную капсулу из тех, чей цвет сейчас открыт на поле;
- «Шаблоны» — сколько из 9 бездумных ботов выигрывают: колонка слева или справа до конца, ряд слева направо, ряд справа налево, змейка, середина и края, по две из колонки, всегда самое большое число, всегда самое маленькое.

Все боты играют как терпеливый игрок: каждый тап доигрывается до конца, только потом следующий.

| Роль | Случайные тапы | Видимый цвет | Шаблонов не больше |
|---|---|---|---|
| Передышка | 60–90% | 85–100% | 6 |
| Обычный | 35–65% | 70–95% | 4 |
| С задачей | 20–40% | 45–75% | 2 |
| Hard | 15–25% | 20–50% | 1 |
| Super Hard | около 10% (6–13%) | до 25% | 0 |

Для сравнения у Colony Flow: L5 Hard — 27% случайными тапами, L10 Super Hard — 18%. L1–4 остаются обучением без ограничений.

## Сборка и проверки

Из корня репозитория:

```sh
node tools/gameplay-pilot-v8c/fix.mjs          # content/pilot-v8c из v8 по ролям
node tools/gameplay-pilot-v8c/verify.mjs       # движок, сертификаты, скрытые варианты, коридоры ролей
node tools/gameplay-pilot-v8c/control-check.mjs
node tools/gameplay-pilot-v8c/clock-check.mjs
python3 tools/gameplay-pilot-v8c/build.py
python3 tools/gameplay-pilot-v8c/compare-art.py
python3 tools/gameplay-pilot-v8c/contact-sheet.py
node tools/gameplay-pilot-v8c/browser-smoke.mjs
node tools/gameplay-pilot-v8c/browser-check.mjs
node tools/gameplay-pilot-v8c/storage-check.mjs
```

Браузерные скрипты, как в v8, ждут `tools/heroanim/node_modules/playwright-core` и `/usr/bin/chromium`. Результаты проверок лежат в [`validation/`](validation/). Боты и шаблоны: `tools/gameplay-pilot-v8c/botsc.mjs`, роли и коридоры: `fix.mjs` и `content/pilot-v8c/quality.json` (`roles`, `roleOf`).

Ограничения:
- Метрики ботов — диагностика авторинга, а не доля побед людей.
- На уровнях с мостиком боты строят мост при первой возможности.
- Победные сертификаты построены на решениях с ожиданием окончания работы.
