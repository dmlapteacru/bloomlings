# Bloomlings — игровые L1–30, итерация 2

Открыть [index.html](index.html) в обычном браузере. Один автономный файл: интернет, установка и APK не нужны. На телефоне скачанный HTML нужно открыть браузером, а не просмотрщиком вложений. Все 30 уровней доступны через кнопку слева сверху. В конце теста: выбор уровней → «Результаты и заметки» → скачать JSON.

Это новая последовательная партия после [плейтеста владельца v1](../../playtests/pilot-v1-owner-2026-10-19/README.md). V1 сохранена отдельно; сохранения и экспорт v2 имеют другую версию. Каталог L1–2500, клиент игры, риги и принятая [визуальная база](../../design/visual-identity.md) не изменяются этим экспериментом.

**Результат ручного теста v2:** [50 попыток и разбор](../../playtests/pilot-v2-owner-2026-10-19/README.md). Два Hard получили явные положительные заметки; узнаются 27 картинок. Нужны правки раннего темпа и видимости очереди; [следующий план](../../plans/gameplay-pilot-v3-plan.md). Сама сыгранная партия ниже остаётся замороженной.

## Что проверяем

- Уже на L1 **9 капсул при 5 местах**. Во всей партии минимум 8 самостоятельных выборов; связанная пара считается одним выбором. Очередь нельзя целиком отправить в пять мест первой серией тапов. Количества разные, а не одинаковые заряды по 10.
- Автоматический **×2 после окончания очереди** сохранён. Заполнение пяти мест само по себе его не включает. Есть и ручное ускорение; правила очистки от скорости не зависят.
- Цветные объёмные клетки с первого уровня, начальная сетка 16×18. Герои знакомят со своими материалами на капсулах. Символы на клетках по умолчанию выключены; их можно включить кнопкой ◇.
- 30 разных крупных силуэтов без прямоугольных рамок ради сложности. [Контактный лист](art-contact.png) позволяет сравнить их до очистки.
- **L6: скрытый цвет.** До выбора нейтральный корпус, вопрос, видимый счётчик; герой и цвет не раскрываются портретом или подписью. Содержимое фиксировано при повторе. Проверены все допустимые скрытые раскладки и общая информационная стратегия без знания скрытого цвета.
- **L10: пары.** Обе капсулы отправляются одним тапом, нужны два свободных места и обе верхние капсулы. **Эксперимент v2: оба места остаются заняты до завершения всей пары.** Готовая половина показывает ✓ и «ждёт пару». Одинаковые буквы ↔ видны и в будущей очереди. В текущем производственном Core освобождение независимое; это сознательное отличие пилота.
- **Hard: L15 / L22 / L25 / L29.** Для каждого есть выигрышный маршрут, полный поиск исключает победу при постоянной занятости не более двух мест после очистки, а два разнесённых полезных на вид выбора имеют доказанные проигрышные продолжения. Хотя бы один эпизод сравнивает действия с общим цветом. Это проверка конструкции, не доказательство человеческой трудности.
- **L18: мостик Sprig. L19 и далее: выбор берега.** В пяти задачах оба мостика доступны в контрольной точке; при замене берега прежняя дальнейшая последовательность уже не выигрывает. Проверка другого маршрута завершается точно, а не результатом Unknown.
- Передышки после сложных задач: L16, L20, L28, L30. Ни один уровень пока не называется Super Hard.

При неверном выборе не подсвечиваем решение. Ретрай бесплатный. У каждой попытки сохраняются принятые действия, активное время, итог, момент автоускорения, оценки узнаваемости/сложности, ответ «шёл по цветам / думал об очереди» и заметка. Автоматической отправки данных нет.

## Порядок знакомства

| Участок | Поле | Содержание |
|---|---|---|
| 1–3 | 16×18 | Sprig / Drop, затем Bloom |
| 4–6 | 18×20 | Twig на L5, скрытые капсулы на L6 |
| 7–10 | 20×22 | Скрытые в практике, светлый материал L8, первая пара L10 |
| 11–15 | 22×24 | Пары, скрытые, очередь; первый Hard L15 |
| 16–21 | 24×26 | Передышка, закрепление; мостик L18, два берега L19, тёмный материал L20 |
| 22–30 | 24×26–28×30 | Знакомые комбинации; Hard L22 / L25 / L29 и передышки |

## Проверка и воспроизведение

Данные: [levels.json](../../../content/pilot-v2/levels.json). Выигрышные повторы, точные ошибочные ветви, скрытые миры и мостики находятся отдельно в [certificates.json](../../../content/pilot-v2/certificates.json); **в игровой HTML решения не включены**. [quality.json](../../../content/pilot-v2/quality.json) содержит диагностические политики и выбранные детерминированные попытки генератора. Проценты ботов не являются вероятностью победы человека; генератор использует их для отбраковки очевидных конструкций, поэтому это также не независимая оценка трудности.

```bash
node tools/gameplay-pilot-v2/verify.mjs
dotnet build tools/gameplay-pilot-v2/check/Bloomlings.Pilot.V2.Check.csproj --artifacts-path /tmp/bloomlings-pilot-v2-dotnet
dotnet /tmp/bloomlings-pilot-v2-dotnet/bin/Bloomlings.Pilot.V2.Check/debug/Bloomlings.Pilot.V2.Check.dll /tmp/bloomlings-pilot-v2-verification/transcripts.json
python3 tools/gameplay-pilot-v2/build.py
python3 tools/gameplay-pilot-v2/contact-sheet.py
node tools/gameplay-pilot-v2/browser-check.mjs
```

Проверочный C# проект компилирует настоящий Core и сверяет точную очистку, возрастной порядок работы, исходную очередь, атомарное размещение пары и раскрытие цвета. Отдельный явно обозначенный адаптер резервирует места до конца пары и добавляет мостик; он не выдаётся за уже существующее поведение Core. Браузерный тест проходит реальные карточки всех 30 уровней, проверяет сохранение, повтор, скачивание результатов, тайминг авто×2 и мобильную компоновку. Итоговые числа и хеши — в [validation.json](validation.json).

Для повторного авторинга: `node tools/gameplay-pilot-v2/generate.mjs --out=/tmp/pilot-v2-rebuild`. По умолчанию до 4 000 детерминированных кандидатов на уровень; можно использовать `--only=15`, `--from=16`, `--to=20`. Изменение данных меняет хеш и создаёт новое пространство сохранений. Генератор не устанавливает ничего в клиент.

Ограничения: узнаваемость и желание переигрывать оценивает следующий ручной плейтест. HTML проверяет концепцию геймплея, не производительность Unity или APK на телефоне. Рисунки этой партии — прототипы, не финальный арт релиза.
