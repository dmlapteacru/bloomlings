# Проверки v6

- `engine.json`: 30 базовых победных маршрутов + 16 маршрутов в двух скрытых мирах; 240 случайных партий с параллельным вводом. Сохранение работы/квот, уникальные резервации, повторное использование места до прибытия, совместное освобождение связок, отсутствие преждевременных терминальных исходов. Более тысячи восстановлений снимков.
- `browser.json`: все 30 уровней пройдены через DOM финального HTML. 36 проверок раскладки; ширины 320/360/390/430/768/1280, зоны нажатия не менее 44 px, очереди без обрезки. Реальный download JSON, повторение команд по времени модели, проверка каждого отправления/снятия/возврата/освобождения. Нет ошибок JS или внешних запросов.
- `clock.json`: переходы активного времени не включают скрытую вкладку, меню и время между перезагрузками.
- `lifecycle.json`: реальные обработчики DOM; пауза меню, эмуляция document.hidden, перезагрузка во время движения. Физическое сворачивание мобильного браузера не проверено.
- `storage.json`: полный набор результатов автоматического DOM-теста с 30 победами помещается в localStorage и читается после перезагрузки. Не гарантия квот хранения всех браузеров.
- `artifacts.json`: хеши HTML/ZIP, тождество HTML в архиве; прежний v5 не изменён.

Автоматическая браузерная проверка использует ускоренные виртуальные часы. Её секунды не являются человеческим временем прохождения. Нативная C#-эквивалентность новых правил не заявляется. Проигрыш в решателе с ожиданием не доказывает проигрыш при любом времени ввода. Ручной тест нужен для оценки интереса, длительности и читаемости.
