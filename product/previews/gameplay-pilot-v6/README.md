# Bloomlings v6 — 30 уровней для телефона

Открыть `index.html` в браузере. Всё встроено в файл; сеть не нужна. Все уровни доступны через меню. Начать с 1× для оценки потока; 2× можно включать вручную. После игры открыть результаты и скачать JSON.

Что изменилось: счётчик уменьшается при отправлении героя; слот освобождается после отправления всей команды; одинаковые цвета работают параллельно. Остатки в закрытых областях занимают место. Семь очередей переработаны: L4/5/7/13/16/18/19. В глубоких очередях область выбора увеличивается, чтобы все строки были видны. L10/15/21/22/25/29 сохраняют контент v5, но работают по новым правилам.

Документ: `product/plans/gameplay-pilot-v6-plan.md`.
Исходники: `tools/gameplay-pilot-v6/`.
Данные и сертификаты: `content/pilot-v6/`.
Проверки: `validation/`.

## Воспроизведение

Из корня репозитория:

```sh
node tools/gameplay-pilot-v6/verify.mjs
node tools/gameplay-pilot-v6/clock-check.mjs
python3 tools/gameplay-pilot-v6/build.py
node tools/gameplay-pilot-v6/browser-smoke.mjs
node tools/gameplay-pilot-v6/browser-check.mjs
node tools/gameplay-pilot-v6/storage-check.mjs
python3 tools/gameplay-pilot-v6/contact-sheet.py
```

Нужны Node, Python/Pillow, Chromium и установленный `tools/heroanim/node_modules/playwright-core`. Текущая среда использует `/usr/bin/chromium`. Браузерные проверки читают автономный HTML через локальный HTTP; публикация сайта не нужна. `generate.mjs` воспроизводимо пересоздаёт только `content/pilot-v6`, не производственный каталог.

Не интерпретировать автоматические времена и оценки ботов как реальные отзывы. Победные сертификаты ждут завершения работы между ходами; параллельный ввод отдельно проверяется на инварианты, но не гарантирует тот же исход. Новые правила пока не перенесены в Unity/C#.
