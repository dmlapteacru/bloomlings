# Проверки v7

- `engine.json`: победные маршруты всех 30 уровней и скрытых вариантов, сохранение объёма работ, параллельные вводы, восстановление событийной модели. Правила, скорость, палитра и часы побайтово равны v6.
- `content.json`: L1–9 перерисованы, L10–30 равны v6. Размеры, входы, число лотов/связок/скрытых лотов и первые появления материалов сохранены. В L6–8 изменился набор уже известных материалов.
- `browser.json`: прохождение всех 30 уровней через DOM автономного HTML, отзывчивая раскладка, восстановление и воспроизведение скачанного JSON по временам команд. Хэш отчёта должен совпадать с `artifacts.json`.
- `clock.json`, `lifecycle.json`: меню/скрытое состояние не начисляют время; загрузка сохранённого потока восстанавливает его состояние. Скрытие вкладки эмулируется DOM-событием, это не измерение физического телефона.
- `storage.json`: результаты полной тестовой сессии записываются и восстанавливаются после перезагрузки браузера.
- `artifacts.json`: хэши HTML/ZIP, целостность ZIP, неизменность HTML v6.

Сравнение `art-before-after.png` показывает точные клетки, а не концепт поверх игрового поля. Изображения также просмотрены в мобильном браузерном рендере. Узнаваемость и интерес оценивает игрок; автоматическая проверка не может подтвердить их. Часы браузера ускорены для QA, времена сертификатов не являются человеческими временами прохождения.

В проверке жизненного цикла поток проверяется через 1600 мс, а не через прежние 800: у нового листа на 800 мс по настоящим правилам в пути только два курьера. Ожидание увеличено в тесте; игровые скорости не изменены.
