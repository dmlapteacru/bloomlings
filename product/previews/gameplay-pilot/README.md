# Bloomlings: первые 30 игровых уровней

Открой [index.html](index.html) в браузере. Это один автономный файл: интернет, установка пакетов и сборка APK для игры не нужны. На телефоне предварительный просмотр вложения может не выполнять JavaScript; нужен запуск в браузере, а не картинка предпросмотра. Нативный Safari на реальном iPhone здесь не проверялся.

- Нажимай верхнюю капсулу в любом столбце. Остаток недоступной работы занимает одно из пяти мест.
- Смотри на точный цвет: два материала одного героя не взаимозаменяемы. Символы включаются кнопкой ◇.
- На L25 Sprig получает одно действие с мостиком. На L28 появляются два места на выбор.
- Кнопка ☷ открывает все уровни; ↻ перезапускает текущий. 2× ускоряет только анимацию.
- Попытки сохраняются в этом браузере после каждого действия. При переносе файла в другое приложение или очистке данных браузера хранилище может отличаться.
- Оценки и заметки необязательны. В выборе уровней → «Результаты и заметки» можно скачать JSON с прохождениями и передать его для разбора.

Внешний вид временный. Принятые герои и визуальная база основной игры [сохранены](../../design/visual-identity.md); основной каталог, экономика и UI не заменены. [Точный состав пилота](../../plans/gameplay-pilot-30.md), [результаты технической проверки](validation.json).

## Воспроизведение разработчиком

Из корня репозитория, Node.js 24 / Python 3 / .NET 10:

```bash
node tools/gameplay-pilot/generate.mjs
node tools/gameplay-pilot/verify.mjs
dotnet run --project tools/gameplay-pilot/check/Bloomlings.Pilot.Check.csproj --artifacts-path /tmp/bloomlings-pilot-dotnet -- /tmp/bloomlings-pilot-verification/transcripts.json
python3 tools/gameplay-pilot/build.py
node tools/gameplay-pilot/browser-check.mjs
```

Генерация пишет только `content/pilot-v1`, не устанавливает уровни в игру. В HTML включаются уровни, но не сертификаты с решениями. Сохранённые JSON уже готовы; повторная генерация для открытия HTML не нужна.

Browser-check использует существующий `playwright-core` из `tools/heroanim/node_modules` и `/usr/bin/chromium`. При отсутствии пакета: `npm ci --prefix tools/heroanim` по существующему lockfile. Временный localhost-сервер нужен только проверке; пользователю он не требуется. Никакой localhost-ссылки для открытия с телефона не публикуем.

Сверка C# компилирует настоящие файлы Core в отдельную проверочную сборку. `Progression` исключена как не относящаяся к правилам поля, `Polyfills` не нужны .NET 10. Новое действие мостика моделирует адаптер, открывающий клетку и вызывающий настоящий Settler. Это не доказательство наличия такого публичного API в текущем клиенте.
