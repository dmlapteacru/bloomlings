# Водный канал Drop: остров за водой — 2026-11-07

Кадры нарисованы самой игрой (полный плейтест, тот же экран, что в APK) на перестроенных уровнях волны L101–L150 по
правилу владельца «Остров за водой» (17 §8, 07.11.2026). Уровни ещё не перенесены в игру: они взяты из
`content/rounds/levels/` во временную папку (`tools/rounds/island-stills.mjs`), а превью играет их правилами раунда
(`core/src/Bloomlings.Core/Rounds/`) по сохранённому решению, без подмен.

Как устроено: внутренняя часть картинки (25–40 % клеток) обведена водой по своим цветовым областям — это контур предмета
или его части, а не случайная рамка. Вода — полоса `#` в оверлее уровня (`overlay.water`), игра рисует её ручьём в
кремовых каменных берегах; утверждённая картинка не меняется. Остров достижим только через канал: оба выхода стоят на
острове с разных сторон, родник снаружи за коротким подходом и открывается на 20–30 % работы сохранённого решения. Выбор
решает, какая сторона острова открывается первой; невыбранный выход входом не становится.

Пересобрать: `node tools/rounds/island-stills.mjs content/work/island-stills 101 110 117 139`, затем
`dotnet run --project playtest/preview -- --island-stills content/work/island-stills <папка>` (около минуты). Здесь:
старт — весь экран 540 × 1170, остальное — кроп доски.
