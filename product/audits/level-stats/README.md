# Статистика уровней: Colony Flow, v8E, v9

Задание владельца от 25.10.2026: статистика уровней Colony Flow по прохождениям, то же для наших v8E и v9 и отдельный раздел сравнения.

- **[`report.html`](report.html)** — отчёт. Один файл, работает без сети и сервера: открыть в браузере на компьютере или телефоне.
- **[`conclusions.md`](conclusions.md)** — выводы и что взять в генератор. Они же — вкладка «Выводы» отчёта.
- **[`unknowns.md`](unknowns.md)** — что осталось неизвестным и какие материалы помогут.
- **[`levels.csv`](levels.csv)** — общая таблица: одна строка на уровень, 97 строк.

## Откуда данные

| Набор | Раскладка | Попытки | Модель |
|---|---|---|---|
| Colony Flow, 37 уровней | восстановлена по видео и обложкам ([colony-flow-rounds](../colony-flow-rounds/README.md)) | каждый тап по времени; места и остаток поля покадрово с видео (`tools/level-stats/observed/`, `videoslots.py`) | наш движок, приближённо: одна норка, муравьи обходят поле по краю. Только 16 уровней без замков, коробок и с полем, которое сходится с капсулами |
| v8E, 30 уровней | сборка от 24.10 (коммит 8892a6f4) | твои 39 попыток ([экспорт](../../playtests/pilot-v8e-owner-2026-10-24/results.json)), переиграны точно | точная |
| v9, 30 уровней | `content/pilot-v9` | нет | точная |

Колонки CSV с приставкой `o_` — победная попытка человека: видео Colony Flow или точный повтор твоей попытки v8E; у v9 их нет. С приставкой `m_` — один и тот же модельный игрок на всех уровнях с моделью: выигрышный путь из перебора, каждый тап после окончания работы. `s_*` — доли побед стратегий.

## Пересобрать

```sh
python3 -I tools/level-stats/videoslots.py --yt <dir> --old <dir> --xrec <dir>   # места и поле с видео (~25 мин)
node tools/level-stats/measure.mjs --part 0/3 & node tools/level-stats/measure.mjs --part 1/3 & node tools/level-stats/measure.mjs --part 2/3   # ~45 мин
node tools/level-stats/assemble.mjs   # out/levels/*.json → out/data.json, levels.csv
node tools/level-stats/validate-cf.mjs --scales 1x1,1.5x1,2x1,3x1,1x1.5   # сверка модели с видео (~15 мин)
node tools/level-stats/plans.mjs CF-25 v8E-15 v9-22 v9-25                    # разные планы
node tools/level-stats/measure.mjs --cf-gap 1.5 --out tools/level-stats/out/levels-cal --only <CF-уровни>   # калибровка
node tools/level-stats/analysis2.mjs  # дополнительные проверки → out/data.json (extra)
node tools/level-stats/report.mjs     # out/data.json + conclusions.md + unknowns.md → report.html
```

Код (`tools/level-stats/`):

| Файл | Что делает |
|---|---|
| `levels.mjs` | общий формат уровней трёх наборов |
| `engines.mjs` | движок каждого набора |
| `trace.mjs` | запись попытки на живой шкале времени |
| `metrics.mjs` | показатели попытки и пять отрезков |
| `static.mjs` | поле и лоток |
| `solve.mjs` | перебор: проходимость, минимум мест, решения, роковой тап |
| `strategies.mjs` | простые стратегии |
| `measure.mjs` | всё по одному уровню |
| `supplement.mjs` | дописывает к старым результатам выигрышный путь в двух темпах |
| `analysis2.mjs` | дополнительные проверки: сопоставимые группы, объём цвета по капсулам, форма связок, конец выборов, v8E против v9 |
| `validate-cf.mjs` | повтор каждой записи Colony Flow на модели и сверка с видео кадр за кадром, в том числе с медленнее выходящими муравьями |
| `plans.mjs` | разные выигрышные планы на нескольких уровнях |
| `cf-engine/` | движок Colony Flow: наш v8E плюс связки Colony Flow, замки, ящики, шоколад, кувшины; масштаб скорости для калибровки |

## Отчёт

Вкладки:
- **Обзор** — фильтры, таблица, CSV, ключевые графики;
- **Уровень**;
- **Стратегии**;
- **Сравнение** — Colony Flow / v8E / v9;
- **Похожесть**;
- **Время**;
- **Полнота**;
- **Выводы**.

У каждого числа есть метка источника: раскладка, запись, повтор, модель или стратегия. «Неизвестно» не равно нулю. Каждый график сохраняется в SVG или PNG.
