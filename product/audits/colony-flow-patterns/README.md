# Паттерны прохождения раундов Colony Flow

30–31.10.2026. Паттерн — последовательность выбранных колонок («1 1 2 3»); связка пишется один раз своими колонками
(«2-3» — то же, что «3-2»; «4-4» — два пода друг под другом в одной колонке). Раунды — точные модели из раскадровок
(`tools/level-stats`, `../colony-flow-rounds/`), движок Colony Flow; «спокойно» — игрок ждёт, пока поле успокоится, перед
каждым тапом (в этой модели повторяются победы владельца на L20, L25, L26).

| Раунд | Колонки | Допы | Выигрышных паттернов | Случайные тапы спокойно | Быстро (тап, как только есть место) |
|---|---|---|---|---:|---:|
| L19 Normal | 3 × 8 | связки, скрытые | 643 230 — все порядки (`CF-19-patterns.txt.gz`) | 100 % | 100 % |
| L26 Normal | 3 × 12 | связки | ~10¹¹ | 67 % | 0 % |
| L25 Hard | 4 (6/8/8/8) | связки, скрытые | ~10¹¹ | 25 % | 19 % |
| L20 Super Hard | 4 (11/12/11/11) | связки, скрытые | ~10¹⁵ | 11 % | 16 % |

Страницы для игры с 10 паттернами: `L19.html`, `L25.html` (в архивах — `index.html`).

## В чём секрет при таком числе паттернов

- **Важна доля, а не число.** Порядков астрономически много, но на Hard и Super Hard большинство проигрывает: L25 — 3 из
  4 случайных порядков, L20 — 9 из 10. Проигрыш случается рано (медиана — 13-й тап из 26 у L25, 8-й из 36 у L20): решают
  несколько первых выборов, дальше порядок почти свободен, отсюда и огромное число побед.
- **Ловушка — связка, у которой работа второго пода закрыта картинкой.** Связка держит два места из пяти, пока не
  закончат оба. L25: белая пара 28 + 51 (колонки 1–2, ряд 1; белое — ободки глаз, семечки клубники) сидит в местах во всех
  100 % проигрышей, пара «голубой 40 + розовый 29» (колонка 4; розовое — уши и щёки внутри тёмной головы) — в 66 %.
  L20: связка «бледно-розовый 35 + зелёный 8» (колонка 1, ряды 2–3; зелёное — листики клубники) — в 86 % проигрышей.
- **Приманка сверху.** Эти связки лежат в верхних рядах и манят взять их сразу.
- **В Normal секрет — темп.** L26 спокойно выигрывается в 67 % случайных порядков, быстро — ни разу из 400: места
  забиваются подами, чей цвет ещё не открыт. L19 лёгкий при любом темпе.

Скрипты: `tools/rounds/analysis/cf-patterns.mjs` (точный счёт и список), `cf-round-page.mjs` (страница), `cf-tempo.mjs`
(темп), `cf-secret.mjs` (что в местах при проигрыше), `cf-pattern-tree.mjs` (дерево решений по выборке).
