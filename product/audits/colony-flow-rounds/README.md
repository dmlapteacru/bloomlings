# Colony Flow: восстановленные уровни и раунды

Все уровни Colony Flow, которые владелец записал на видео, в виде текста, который может прочитать любой агент. Видео лежат в бакете владельца (`https://pub-dc09455922e746b0979cdaa7317edd10.r2.dev/<имя файла>`), в репозиторий их не кладём.

- **`levels.json`** — всё в одном файле (формат `colony-flow-rounds-1`, описание ниже).
- **`L01.md` … `L26.md`** — раскадровка каждого уровня: поле буквами, цвета, очередь, раунды по времени.
- **`frames/board-l<N>.jpg`** — кадр начала уровня, по нему распознано поле.
- **`checks.json`** — результат проверок сборки.
- **[`site/`](site/README.md)** — ещё 28 уровней (L19–L1270) из видео прохождений с colony-flow.com: поле с обложки сайта, очередь, замки и ключи, шоколадки и ящики, каждый тап.

## Формат `levels.json`

Для каждого уровня:

- **`board`** — `w`, `h`, `rows` (сверху вниз, одна строка на ряд), `legend` (буква → название и цвет). `.` — пустая земля, `?` — клетка-загадка на поле.
- **`tray`** — колонки `c1`, `c2`, …, капсулы сверху вниз. Токен: буква цвета + число клеток, например `D30`.
  - `D30?` — капсула показана как «?», пока не станет верхней;
  - `W28:a` — связка `a`: один тап берёт все капсулы связки, и все они должны быть сверху (или прямо под другой капсулой той же связки в той же колонке). Пояснение к связкам — в `linkNote`.
- **`capacity`** — мест ожидания (у всех 5).
- **`accounting`** — для каждого цвета клетки на поле и в капсулах.
- **`rounds`** — раунды по видео:
  - `attempt`, `outcome` (`won` / `lost`), `start`, `end` (секунды записи);
  - `taps`: `t` — время тапа, `column` — колонка, `take` — какие капсулы ушли в места ожидания (сборка воспроизводит тапы на очереди и записывает это сама), `note`;
  - `events` — важные моменты: завершения, ожидания, проигрыш;
  - `trayLeft` — сколько капсул осталось в очереди.
- У L1–L5 и L10 раунды разложены по тапам 25.10 (`tools/colony-deep-research/rounds/owner-1020/`); текст разбора 20.10 сохранён в `storyboardText`. Раунд, снятый несколькими файлами, перечисляет их в `videos`.
- **L4:** вторая запись продолжает ту же попытку; тап зелёной 24 пришёлся на разрыв между файлами (время примерное).
- **L5:** запись начинается после первых четырёх тапов (они поставлены на 0 с) и обрывается, когда в лотке ещё 3 капсулы: исход не виден.

Заметки к L20, L25 и L26 (картинка, события) — на английском, чтобы их одинаково читали и люди, и скрипты; остальное — на русском.

## Как получено и насколько точно

| Уровень | Поле | Очередь | Время тапов |
|---|---|---|---|
| L1–L5, L10 | кадр начала, `gridmap.py` | целиком из партий ([разбор 20.10](../colony-flow-levels-deep-dive-2026-10-20.md)), подтверждена видео 25.10 | по раскадровке записей (`ytsheets.py`, 25.10), ±0,25 с; запись из нескольких файлов — время от начала первого |
| L20 | кадр начала | целиком из партии (`tools/colony-deep-research/sim/l20.json`) | найдено автоматически, ±0,5 с: рост числа занятых мест (`slottaps.py`) и движение в лотке (`traytaps.py`), сопоставлено с порядком тапов (`rounds/align20.mjs`) |
| L25, L26 | кадр начала, `cfcells.py` (каждый кубик, включая фон) | прочитана по кадрам каждые 0,5 с, пока капсулы поднимались наверх | прочитано по тем же кадрам, сверено с `slottaps.py` и `traytaps.py` |

**Проверки сборки:**
- суммы капсул сходятся с полем (кроме отмеченного выше);
- каждый тап каждого раунда берёт капсулы, которые в этот момент сверху, и связку целиком;
- после выигранного раунда очередь пуста.

## Пересобрать

```sh
node tools/colony-deep-research/rounds/build.mjs
```

Данные L25 и L26 — `tools/colony-deep-research/rounds/data-l25-l26.mjs`. Новый уровень: распознать поле (`python3 -I tools/colony-deep-research/cfcells.py <кадр.png> 40,134,332,392 <префикс>` для записи 368×816), выписать очередь и тапы по кадрам, добавить в данные и пересобрать.
