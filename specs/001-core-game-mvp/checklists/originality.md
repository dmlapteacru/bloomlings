# Originality review (T154)

**Feature**: 001-core-game-mvp · **Requirement**: FR-091 · **Date**: 2026-09-29

FR-091: the game must not reuse Colony Flow's name, characters, art, audio, level pictures or interface graphics. Only
the gameplay rules and structure are similar.

## Automated checks (done; `core/tests/Bloomlings.Content.Tests/OriginalityTests.cs`, run locally before every push)

- [x] The reference game's name (and its publisher's) appears nowhere in `client/Assets/`, `content/pictures/` or
  `content/curated/`. The design documents in `product/` and `specs/` name it only as the gameplay reference.
- [x] `client/Assets/` contains no imported art, audio or font files without a licence record. Visuals are procedural
  placeholder art drawn in code (`Art/Procedural/ProceduralSprites.cs`: tiles, pods, family silhouettes, icons,
  accessories and UI shapes) or the project's own generated character art (spec 004, below). Sounds are synthesized.
- [x] The character art of spec 004 (`Art/Characters/Resources/Characters/`: 48 2D characters, 8 hero pictures, the
  group) is generated by `tools/artgen` from code in this repository and recorded as the project's own work
  (`tools/artgen/OWNERSHIP.md`, a folder row in `client/THIRD_PARTY_NOTICES.md`). The originality test accepts exactly
  the files of its `manifest.json`, `CharacterArtTests` checks their hashes, and `tools/artgen check` proves they come
  from the tool. The owner's reference screenshots set a direction only; nothing was traced or copied from them or from
  the reference game.
- [x] The owner's animated heroes and layered Home (spec 005 FR-028): the frames in `Art/Heroes/Resources/HeroMotion/`
  are covered by a folder row in `client/THIRD_PARTY_NOTICES.md` (the test accepts exactly the files of the folder's
  `manifest.json`, each naming its source record `tools/heroanim/SOURCE.md`), and each Home layer has its own row;
  `node tools/heroanim/check.mjs` proves the committed files come from the bake and the layer run. The Meshy plan is
  still to confirm (below).
- [x] All 107 pictures in `content/pictures/lib/` have `source.licence` `owned`:
  - 13 were drawn by the Bloomlings team;
  - 94 were generated by `content/pictures/tools/sketch_pictures.py` from the team's own grids in
    `content/pictures/src/`.
- [x] The characters are original: the four families (Sprig, Bloom, Drop, Twig), the eight variants, their icons and
  their character shapes (spec 004).
- [x] The name "Bloomlings", the Spirit Pod, Waiting Slot and Garden Entry terms, and all UI strings
  (`UI/Localization/Resources/Strings_en.csv`) are original.
