# Originality review (T154)

**Feature**: 001-core-game-mvp · **Requirement**: FR-091 · **Date**: 2026-09-29

FR-091: the game must not reuse Colony Flow's name, characters, art, audio, level pictures or interface graphics. Only
the gameplay rules and structure are similar.

## Automated checks (done; `core/tests/Bloomlings.Content.Tests/OriginalityTests.cs`, run on every push)

- [x] The reference game's name (and its publisher's) appears nowhere in `client/Assets/`, `content/pictures/` or
  `content/curated/`. The design documents in `product/` and `specs/` name it only as the gameplay reference.
- [x] `client/Assets/` contains no imported art, audio or font files. Every visual is procedural placeholder art drawn in
  code (`Art/Procedural/ProceduralSprites.cs`): tiles, pods, Bloomling silhouettes, icons, accessories and UI shapes.
  There is no audio yet.
- [x] All 107 pictures in `content/pictures/lib/` have `source.licence` `owned`:
  - 13 were drawn by the Bloomlings team;
  - 94 were generated by `content/pictures/tools/sketch_pictures.py` from the team's own grids in
    `content/pictures/src/`.
- [x] The characters are original: the four families (Sprig, Bloom, Drop, Twig), the eight variants and their icons.
- [x] The name "Bloomlings", the Spirit Pod, Waiting Slot and Garden Entry terms, and all UI strings
  (`UI/Localization/Resources/Strings_en.csv`) are original.
