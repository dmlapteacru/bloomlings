# Daily Challenge 2027 — картинки владельца (01.11.2026)

365 картинок, одна на каждый день 2027 года, из трёх ZIP владельца («Bloomlings Daily 2027», части 01–04, 05–08, 09–12;
6 ноября — день рождения разработчика, новая сцена в части 3).

- `json/` — матрицы (`P####.json`), `png/` — картинки с сеткой.
- `parts/<часть>/` — `calendar-map.json` (дата → картинка, идея, подпись), `data.json`, `qa-summary.json`, `palette.json`,
  `year-notes.md`, README и подписи части.
- `Daily-2027-dates-and-captions-RU.md` — полный календарь с подписями (обновление с днём рождения).

**Коды — отдельное пространство Daily.** Владелец пронумеровал их P0468–P0832, а P0468–P0470 в кампании уже заняты
контурными картинками мостов (`content/rounds/pictures/`). Поэтому эти картинки не внесены в `content/rounds/pictures/`
и в пул кампании; при работе с Daily им дадут свои коды по дате (решение — вместе с владельцем).

Не перенесено: превью (`review/`, `blind/`, PDF) и папка `repository/` из ZIP — в ней более старые версии наших
инструментов (`tools/rounds/lib.mjs` с палитрой на 16 цветов) и конвейер Daily v2; их сверим, когда начнём работу с Daily.

Владелец, 01.11.2026: «Пока что картинки надо добавить в репо и утвердить все… картинки daily challenge… с ними будем
работать после калибровки».
