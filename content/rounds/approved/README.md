# Approved round pictures

Generated by `node tools/rounds/pictures.mjs publish` (approve, reject and replace run it). Do not edit by hand.

- `sheet.png`: all of them on one contact sheet.
- `locked/L000N.json` + `.png`: the pictures locked to levels 1–3 (rule 17 §4).
- `pool/P####.json` + `.png`: every other approved picture. They are interchangeable between rounds: a picture's number does not
  assign it to a level; the level skill `bloomlings-round-levels` places each one by its measured class and the stage
  ranges it fits (the Stages column).

Each JSON holds the matrix (`rows`, top first, `.` empty), its size, cell count, colours and the volume of each material.
