# Approved round pictures

Generated by `node tools/rounds/pictures.mjs publish` (approve, reject, replace and `levels.mjs place` run it). Do not edit by
hand.

Every picture has a code, `P####`: its file name, its JSON's `code` and the number on `sheet.png`. A code is **free** until a placed
level in `content/rounds/levels/` uses it, then **in a round** (`usedBy`: the level). Free now: **360**, in rounds: **50**.

- `locked/P####.*`: the pictures locked to levels 1–3 (rule 17 §4); only that level may use them.
- `pool/P####.*`: every other approved picture. They are interchangeable between rounds: a code does not assign a
  level. `bloomlings-round-levels` places each one by its measured class and the stage ranges it fits (Stages).
- `sheet.png`: all of them; a green number is free, a grey one is in a round (#N: its level).

Each JSON holds the code, state, matrix (`rows`, top first, `.` empty), size, cell count, colours and the volume of each
material.
