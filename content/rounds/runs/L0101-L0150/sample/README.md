# Bloomlings v12 — первые 15 уровней раундов

[Скачать ZIP для телефона](Bloomlings-pilot-wave-101-150.zip). Распакуй и открой [index.html](index.html). Сеть не нужна, все уровни открыты в меню. После игры: Уровни → Результаты → скачать JSON.
