# Bloomlings v12 — первые 12 уровней раундов

[Скачать ZIP для телефона](Bloomlings-pilot-wave-101-150.zip). Распакуй и открой [index.html](index.html). Сеть не нужна, все уровни открыты в меню. После игры: Уровни → Результаты → скачать JSON.

Уровни построены скилом `bloomlings-round-levels` по [правилам 17](../../17_LEVEL_GENERATION_RULES.md) из утверждённых картинок (`content/rounds/approved/`) и сыграны в браузере их сохранёнными решениями. Страница играет тем же движком раундов (`tools/rounds/engine/`), на котором уровни решены и измерены.
