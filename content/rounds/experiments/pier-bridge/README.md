# Ярмарка на пирсе: второй Super Hard волны (L45)

30.10.2026. Владелец о «коробке на старте»: «Я не имел в виду конкретно сейчас коробку сделать… это потенциально может
быть как один из подходящих вариантов в зависимости от уже самой картинки… для шатра и для колеса обозрения придумаю
что-нибудь связанное… сделай одну общую картинку, и там дальше уже где-то сделай разрыв и место для мостов, как ты
сделал с предыдущим суперхардом».

## Картинка

P0154 v4 (`pier.py`, `content/rounds/pictures/src/batch-0154-fair-pier.mjs`; черновик, ждёт владельца):

- ночная ярмарка на деревянном пирсе над морем: колесо обозрения на зелёной площадке и полосатый шатёр;
- нейтральная линия (полоса `gap`) обводит пирс вместе с колесом и шатром, как остров у пагоды;
- мосты — сходни: с пляжа к передней части пирса (решает, выводит на настил) и с лодки к левому краю (выводит на
  площадку колеса, её поды идут поздно);
- море и ночное небо — фон, их докрашивают в конце; небо, видное сквозь колесо и вход в шатёр, принадлежит предмету.

Пирс не касается краёв картинки, обхода мимо сходней нет. Карманы неба, которые линия заперла бы между колесом и шатром,
`pier.py` отдаёт предмету.

## Очередь

Поиск — `search.mjs` (тот же, что у острова): `APPROACH=["A","V"]` (пляж, лодка), `ENTRY=E` (настил),
`MID=["O","R","C","Y"]`, `LAST=L` (площадка колеса), `OUT=["B","N"]` (море, небо), 4 колонки, `FARSIZE=20`, `EARLYN=4`,
отбор по 100 партиям в 8–20 % (быстрая оценка на 80 партиях давала кандидатов, которые в полной проверке падали ниже 5 %).
Кандидат 222-0 (`level-v1.json`, `preview-L0045.json`):

## Проверка

`full.mjs`, `levels.mjs evaluate`, вид `single`, Super Hard.

| | |
|---|---|
| Каждый мост отдельно (решатель) | левые сходни — проигрыш, передние — победа |
| **Случайный тест с передними сходнями (класс, §5)** | **11 % из 100, Wilson95 6–19 % → Super Hard** |
| Случайный тест с обоими (справка) | 5 % из 400 |
| Первым предлагается | левые в 21, передние в 39 партиях из 60 |
| Неверные сходни | проигрыш не сразу: медиана — ещё 2 запуска после выбора |
| Вынужденные решения | 15 % |
| Дебют + цвета | проходит (жадная не выигрывает ни после одного, ни после трёх запусков) |
| Простые стратегии | все 16 проигрывают |
| Стоят без работы (слой B, Super Hard ≥ 2,0) | 2,23 |
| Решение | 28 действий, около 8 минут при ×1 |

34 пода, 4 колонки, 7 пар связок (с первого ряда до седьмого; 14 из 34 — 41 %), 2 скрытых. Картинка — 928 клеток,
10 цветов, 32×32. Уровень не закреплён: ждёт, пока владелец посмотрит картинку (`levels.mjs adopt 45 preview-L0045.json`
после утверждения P0154).
