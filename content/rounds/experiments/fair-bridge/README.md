# Ночная ярмарка за каналом: второй Super Hard, собранный вручную

30.10.2026. Владелец принял два решения: класс уровня с мостом меряется случайным тестом с решающим мостом (17 §5), а
все Super Hard и уровни с мостом строятся вручную (17 §13 «Кто строит уровни»). И попросил: «сделай тогда сам 2-й
super hard». По плану волны это L45: мост (решает ровно один) + связки + 2 скрытых.

## Картинка

Черновик P0154 (`fair.py`, `content/rounds/pictures/src/batch-0154-fair.mjs`; ждёт утверждения владельца):
колесо обозрения с огнями и полосатый шатёр под луной. Семейство «Ярмарки и праздники» есть в списке мостовых
семейств волны, и картинок в нём ещё нет. 968 клеток, 9 цветов.

Рецепт сада ([../garden-bridge/README.md](../garden-bridge/README.md)), отражённый, чтобы решал **левый** мост:

- на ближнем берегу клумбы: слева мох M, справа румянец K, между ними дорожка;
- за каналом карманы крест-накрест: слева румянец, справа мох; по краям картинки они закрыты, выход только вверх.

## Поиск

`search.mjs` — поиск сада с `WIN=0`:

- скелет очереди: мох для левой клумбы первым, румянец для правой клумбы и левого кармана следом, мох для правого
  кармана последним;
- `SK=A`: поды обеих клумб рядом. Второй скелет почти всегда первым предлагал только верный мост, то есть выбора не
  было;
- связки — доза ведущей Super Hard (от 35 % подов): 3 пары в первых трёх рядах, остальные в середине;
- отбор: только левый мост выигрывает; левый мост отдельно — 6–20 %; вынужденные решения ≤ 35 %; дебют + цвета; оба
  моста хоть иногда предлагаются первыми; «стоят без работы» не ниже `PMIN`.

Давление на места у этой картинки выше 1,84 не поднялось ни у одного из 10 кандидатов, у которых его мерили. Причина —
сама картинка: ночное небо подходит к земле между колесом и шатром и открывается сразу после неё. Поэтому `PMIN=1.7`.
Полную проверку (`full.mjs`) прошли все пять отправленных на неё кандидатов (12–19,5 % с левым мостом); взят 54-10 — у него выше давление, поровну
предложений и меньше вынужденных решений.

## v2: картинка одним целым

как одно большое целое». Рецепт тот же, части нарисованы ярмаркой (`fair3.py`, картинка P0154 v2, черновик):

- перегородка — канал через ярмарочную площадь в бассейн, края — вода вокруг;
