# Ночная ярмарка: старт в коробке (проба)

**Не стала уровнем L45.** Владелец: «Я не имел в виду конкретно сейчас коробку сделать… это потенциально может быть как
один из подходящих вариантов в зависимости от уже самой картинки». L45 — «Ярмарка на пирсе»
([../pier-bridge/README.md](../pier-bridge/README.md)). Коробка остаётся пробой контура для картинок, которым она подходит.

30.10.2026. Владелец о «Пагоде на острове»: «Вот это хорошо… не просто простую линию одну, а какую-то обводку вокруг
или где-то ещё, или начинать с какого-то бокса конкретно… разные контуры, разные ловушки или разные проходы… Именно
супер харды… передел во второй. Давай их залочим». Это второй Super Hard волны (L45) в другом контуре: не обводка
предмета, а **коробка на старте**.

## Картинка

P0154 v3 (`fairbox.py`, `content/rounds/pictures/src/batch-0154-fair-box.mjs`): колесо обозрения с огнями, полосатый
шатёр под луной, ярмарочная площадь, кусты по нижним углам.

- Ворота ведут на входную площадку — деревянный настил с кассой. Её огораживает нейтральная линия (полоса `gap`),
  которая доходит до нижнего края с обеих сторон, поэтому из ворот можно попасть только на площадку.
- Из площадки два выхода-мостика: через верхний забор на площадь (решает) и через левый забор в кусты.
- Работа до мостов — только площадка (настил и касса, 71 клетка); всё остальное за контуром. Поэтому с неверным мостом
  застревает вся очередь: так «коробка» надёжнее обводки, решающим оказывался ровно один мост у всех кандидатов.
- Подходы разных цветов: к верхнему выходу — настил, к левому — касса; первым предлагается то один, то другой мост.

## Очередь

Поиск — тот же `search.mjs`, что у острова: `APPROACH=["E","K"]` (настил, касса), `ENTRY=D` (площадь),
`MID=["R","C","Y","O","N"]`, `LAST=M` (кусты), фона до мостов нет (`OUT=[]`), 4 колонки, `FARSIZE=20`, `EARLYN=4`.
Кандидат 204-5 (`level-v1.json`, `preview-L0045.json`):

```
         кол. 1   кол. 2   кол. 3   кол. 4
ряд 0:   E29~A    E28~A    K15~B    O19~B     настил (к верхнему мосту); касса (к левому) в связке с огнями — ждут
ряд 1:   Y17      N51~C    D21~C    D21       площадь (за решающим мостом)
ряд 2:   D21?     D21      D21      D21
ряд 3:   N51~E    N52~E    N52      R24       середина
ряд 4:   R24~D    C20~D    C19?     R24       середина
ряд 5:   Y17      C19      N52~G    C20~G     середина
ряд 6:   N52      C20      M34~F    M34~F     кусты (сюда выводит левый мост)
ряд 7:   M34      M34      M33      M33
```

## Проверка

`full.mjs`, `levels.mjs evaluate`, вид `single`, Super Hard; уровень был поставлен на L45 (`levels.mjs adopt`, аудит OK) и снят (`unplace`) после замечания владельца.

| | |
|---|---|
| Каждый мост отдельно (решатель) | верхний — победа, левый — проигрыш |
| **Случайный тест с верхним мостом (класс, §5)** | **11 % из 400, Wilson95 8–14 % → Super Hard** |
| Случайный тест с обоими мостами (справка) | 0 % из 100 |
| Первым предлагается | верхний в 16, левый в 44 партиях из 60 — ловушка чаще первой |
| Неверный мост | проигрыш не сразу: медиана — ещё 2 запуска после выбора |
| Вынужденные решения | 15 % |
| Дебют + цвета | проходит (жадная не выигрывает ни после одного, ни после трёх запусков) |
| Простые стратегии | все 16 проигрывают |
| Стоят без работы (слой B, Super Hard ≥ 2,0) | 2,27 |
| Решение | 26 действий, около 6,5 минуты при ×1 |

32 пода, 4 колонки, 7 пар связок (с первого ряда до седьмого; 14 из 32 — 44 %), 2 скрытых. Картинка — 933 клетки,
9 цветов, 30×32. Мягкие замечания аудита: опасных развилок 2 (ориентир 3–8), последний запуск при 96 % W.
