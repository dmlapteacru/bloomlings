# Замок за рвом: один решающий мост по рецепту v8E L22

30.10.2026, по просьбе владельца: остановить остальное и найти рецепт одной картинки с двумя мостами и одним решением.

**Рецепт v8E L22** («Домик у ручья», владелец: «Хороший уровень», `tools/gameplay-pilot-v8e/scenes.mjs` `sceneLevel`):
на ближнем берегу две грядки разных цветов (слева P, справа Q), опора каждого моста стоит в своей грядке; за рвом
полосы перекрещены (за левым мостом Q, за правым P) и разделены перегородкой; какой мост открывать — решает очередь.

**Что пришлось добавить** (без этого оба моста всегда выигрывали):
- полосы за мостами — «карманы» по 6 рядов: закрыты по краям картинки (`#`), выход только вверх, в картинку;
  иначе по обходной дорожке можно было попасть на чужую полосу в обход моста;
- очередь собрана вручную: мох на правую грядку (открывает правый мост), тыквы на левую грядку и в правый карман,
  потом картинка от правого кармана вверх, мох для левого кармана — в самом конце. С левым мостом тыквам негде
  работать, места забиваются.

**Проверка движком** (`full.mjs` → `levels.mjs evaluate`, вид `single`):

| | |
|---|---|
| Каждый мост отдельно (решатель) | левый — проигрыш доказан, правый — победа |
| Случайный бот только с правым мостом | 85 % |
| Случайный бот в целом (400 партий) | 6,5 % → Super Hard |
| Предлагаются оба места | да (первым левый в 56 из 60 партий, правый в 6) |
| Проигрыш с левым мостом | через ~2 запуска после выбора, не сразу |
| Дебют + цвета, жадные стратегии | проходят |

Файлы: `castle.py` (картинка), `hand.mjs` (очередь и вердикты), `full.mjs` (полная проверка и уровень для пилота),
`level-hand-v1.json`, `preview-L0030.json`. Картинка — черновик P0152, не утверждена.
