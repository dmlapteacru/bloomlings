## Очереди (поиск 01.11.2026; остановлен по просьбе владельца, работа не закончена)

Картинки утверждены 01.11. Поиск — `search.mjs` (обобщение `../contour-bridges/search3.mjs`: вид `better` и `single`
как у `../island-bridge/search.mjs`, скрытые клетки через `levels.mjs pickHiddenCells` — ровно ceil(5 % N) после

`accentCheck`, превью для пилота и `levels.mjs adopt`). Оба скрипта читают картинки из `ROUNDS_DIR` (по умолчанию
`content/rounds`) и пишут только в свою папку вывода; поиск шёл на частной копии `content/rounds` в `/tmp/cb51/`.
Скрипты запусков с параметрами всех партий — `candidates/run-*.sh` (пути `/tmp/cb51/...`; правка поиска — 4 колонки,
`APFIRST`/`APGAP`/`APMIX` для подходов). Принятые уровни — `level-L00NN.json` (определение), `preview/L00NN.json`
(уровень `full.mjs`); `adopt` — родительская сессия после прогона волны.
