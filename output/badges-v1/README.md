# Bloomlings — бейджи v1

23 отдельных PNG: 12 достижений, 7 престижных и 4 тематических. По одному основному дизайну на бейдж, без ступенчатых вариантов. Сгенерировано встроенным image_gen 11 октября 2026.

Прозрачные оригиналы сохранены без обработки. Размеры оригиналов могут отличаться; подготовка размеров для импорта и варианты для маленького аватара не входят в этот набор. В игру изображения пока не подключены.

- `all-badges-preview.png` — общий лист с названиями.
- `achievements/`, `prestige/`, `collections/` — отдельные оригиналы.
- `manifest.json` — названия, источники и точные промпты.
- `prompts.json` — базовый стиль и описания символов.
- `image-checks.json` — размеры и проверка альфа-канала.

Стиль опирается на существующие арты Bloomlings: глянцевые листья и лепестки, мягкий объём, тёплое дерево и кремовые вставки.
