# Sprig — более милый вариант

Новый вариант персонажа для тестового моделирования в Meshy / Tripo. Четыре ракурса в T-позе
на одном листе: FRONT / RIGHT SIDE сверху, LEFT SIDE / BACK снизу.

Направление: круглая мордочка и пухлые щёки, тёплые выразительные глаза, компактная корона
из широких мягких листьев, маленькое тело и короткие конечности. Исходный Sprig сохранён
в `../turnarounds-2026-10-16/sprig-four-views.png`.

Сгенерировано ImageGen по исходному листу Sprig, 2026-10-16. Точный промпт — `prompt.json`.
Это референс нового дизайна, а не рендер готовой 3D-модели: между ракурсами возможны небольшие
расхождения, которые нужно проверить при моделировании. Игровые ассеты не заменены.

В режиме multi-view подавать ракурсы раздельно, не использовать общий лист как один фронтальный
вид. Для первого теста: около 10 000 quads, текстура 2048×2048, экспорт GLB с UV и текстурами.
