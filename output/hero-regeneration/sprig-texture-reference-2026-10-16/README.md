# Sprig — референс текстуры для Tripo

`sprig-texture-reference.png` — фронтальный вид выбранного Sprig A в T-позе, четыре пальца
на каждой руке. Направление: светлая кремово-фисташковая кожа, чистые зелёные стилизованные
листья, мягкая матовая поверхность, карие глаза и нежный румянец. Меньше глянца и мелких деталей.

Использовать для перетекстурирования существующей модели. Это целевой визуальный референс,
не UV-атлас. При работе сохранять сетку и UV: новые карты можно подключить к исходному ригу;
экспорт сервиса сам по себе не гарантирует сохранение костей и весов.

Короткий текстовый ориентир:
“Stylized cozy mobile game character, matte creamy pistachio skin, soft satin spring-green
leaves with simple broad creases, dark brown eyes, subtle peach blush, clean readable color
areas, no realistic leaf veins, no metallic or wet plastic finish, no baked dramatic lighting.
Preserve the existing geometry and UV layout.”

Референс создан ImageGen 2026-10-16 по рендеру фактической модели владельца и выбранному
фронтальному концепту с четырьмя пальцами. Промпт — `prompt.json`, контрольная сумма — `manifest.json`.
Модель, игровые текстуры и риг не заменены.
