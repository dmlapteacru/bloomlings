# Sprig — отдельные референсы формы летних аксессуаров

По просьбе владельца сгенерированы три отдельные картинки для пробы в Tripo:

- `sprig-summer-cap-clay.png` — невысокая кепка с закруглённым козырьком и объёмной ромашкой.
- `sprig-summer-glasses-clay.png` — круглые очки с раскрытыми дужками и отдельными линзами.
- `sprig-summer-backpack-clay.png` — компактный рюкзак с двумя листовыми формами клапана,
  передним карманом с ромашкой, верхней ручкой и плечевыми лямками.

Основа — одобренный общий магазин аксессуаров, ячейка Sprig / Summer. Каждый предмет
показан отдельно в ракурсе три четверти, на белом фоне, без персонажа. Использован
нейтральный серый материал: на этом этапе важна форма, текстуры будут другими.
Ромашки и листья показаны рельефными формами, а не нанесёнными изображениями.

Это сгенерированные референсы для восстановления геометрии, не готовые 3D-меши;
размер и посадка на героя пока не проверены. Игровые ассеты не менялись.

Создано ImageGen 2026-10-16. Полные промпты и исходники — `prompts.json`;
размеры PNG и SHA-256 — `manifest.json`.
