# Sprig — новый выбранный образ из Home Screen Heroes guide

Владелец выбрал новый фронтальный концепт по своему референсу с четырьмя героями:
крошечное тело, пухлая мордочка, короткие лапки, объёмные игровые листья и асимметричный хохолок.

- `sprig-front-concept.png` — исходный выбранный образ; отдельные пальцы потребовали исправления.
- `sprig-front-mittens.png` — уточнение рук по просьбе владельца: **цельная округлая ладонь
  и один отдельный большой палец**, без остальных отдельных пальчиков. Руки остаются частью тела,
  без тканевых перчаток.
- `sprig-front-fingers-straight.png` — следующий вариант по просьбе владельца: снова четыре
  коротких пальца (три пальчика и большой), ладони раскрыты; голова выровнена и взгляд направлен
  прямо на зрителя. Сравнить с вариантом-варежками. Промпт — `fingers-straight.prompt.json`.

- `sprig-four-views-tpose.png` — четыре вида нового Sprig с четырьмя пальцами: спереди,
  лицом вправо, лицом влево и сзади. Руки разведены в T-позу; на боковых видах они укорочены
  проекцией. Вторая генерация уточнила боковые профили, скрыв дальний глаз.

Первые три изображения — фронтальные концепты в свободной позе; новый лист — референс
для моделирования в Meshy/Tripo. Боковые и задний виды интерпретированы ImageGen по фронту,
это не точные ортографические рендеры готовой 3D-модели: согласованность геометрии нужно
проверять после генерации меша. Промпты двух шагов — `four-views.prompt.json`.

Референсы задают внешность следующей версии, не меняют уже созданный экспериментальный риг
старой модели, текстуры или игровые кадры. Базовый образ выбран пользователем;
руки уточнены отдельно.

Изображения созданы ImageGen 2026-10-16. Источник первого — приложенный пользователем
Bloomlings HOME SCREEN HEROES / Idle Animation Guide. Промпты — `prompts.json`, размеры и
контрольные суммы — `manifest.json`.
