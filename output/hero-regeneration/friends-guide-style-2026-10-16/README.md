# Bloom, Drop и Twig — концепты в стиле нового Sprig

Владелец попросил нарисовать остальных героев такими же милыми, как выбранный новый Sprig.
`bloom-drop-twig-front-concepts.png` — общий фронтальный лист: крупные выразительные головы,
маленькие пухлые тела, короткие лапки, раскрытые кисти с четырьмя пальцами.

Основной стилевой референс — `../sprig-guide-style-2026-10-16/sprig-front-fingers-straight.png`.
Старые фронтальные референсы остальных героев использованы для узнаваемости цветка,
капли и жёлудя. Это новые концепты для выбора внешности; они ещё не утверждены владельцем
и не являются T-позами или точными рендерами готовых мешей. Игровые ассеты не заменялись.
