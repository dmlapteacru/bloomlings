# Причёски героев — восемь первых концептов

Владелец попросил по две причёски для каждого героя на одном изображении.
`bloomlings-eight-hairstyles.png` — общий лист, четыре столбца героев и два ряда вариантов.

| Герой | Верхний ряд | Нижний ряд |
| --- | --- | --- |
| Sprig | Leaf Bob — округлое каре из широких листьев | Sprout Quiff — высокий листовой хохолок |
| Bloom | Petal Buns — два пучка-розетки из лепестков | Petal Bob — лепестковое каре с боковой чёлкой |
| Drop | Wave Curl — один крупный водяной завиток | Twin Ripples — два боковых водяных завитка |
| Twig | Bark Curls — округлые древесные кудри под шапочкой | Bark Sweep — гладкие древесные пряди набок |

Формы используют собственный материал каждого героя: листья, лепестки, воду и
стилизованную древесину. Это варианты естественной причёски/макушки, не дополнительные
покупные шляпы. У Twig сохраняются жёлудевая шапочка, стебель и лист.

Это предложения для выбора внешности, ещё не утверждённые владельцем, не готовые
меши и не проверенные сменные детали. Для отдельных причёсок потребуются решения
по отделению базовой макушки, стыкам и посадке; совместимость с кепками не проверялась.
Игровые ассеты не менялись.

Создано ImageGen 2026-10-16 на основе выбранных новых героев. Источники и полный промпт —
`prompt.json`; размеры и SHA-256 — `manifest.json`.
