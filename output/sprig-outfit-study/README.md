# Sprig — пример головы в кепке, очков и рюкзака

Владелец передал пять FBX 2026-10-16 для проверки одного собираемого героя:
`SprigHero.fbx`, `SprigHero@Anims.fbx`, `SprigHero_Cap.fbx`,
`SprigHero_Glasses.fbx`, `SprigHero_Backpack.fbx`.

## Результат

Одна сборка, один скелет из 25 костей, четыре исходных меша. Кепка и очки уже имеют
жёсткие веса на Head, рюкзак — веса Chest/Spine/Hips. Положение, масштаб и матрицы
покоя скелетов совместимы. Исходные вершины, UV, веса и материалы сохранены.

В основной модели уже есть **CapOn** — подготовленное владельцем состояние головы.
Переключатель «Голова в кепке» одновременно включает CapOn=1 и кепку; при выключении
возвращает CapOn=0 и исходную причёску. Верхняя причёска с кепкой не совмещается.
Боковые листья остаются частью присланного варианта головы. Очки и рюкзак независимы.
Новая сетка головы не генерировалась и не вырезалась из исходной.

`viewer.png` показывает настоящий интерфейс примера; остальные PNG и `review.mp4`
отрендерены из фактического экспортированного GLB. Они не созданы ImageGen.

## Как проверить

Скачать и распаковать `sprig-outfit-study.zip` (файл подготовлен в `content/work/`).

1. Открыть `sprig-outfit-viewer.html` в современном настольном браузере. Модель и
   Three.js встроены в один HTML, загрузок библиотек с внешних сайтов нет.
2. Переключать голову в кепке, очки и рюкзак; выбрать движение, скорость и ракурс.
   Модель вращается перетаскиванием, масштабируется колёсиком.
3. Для редактирования открыть `sprig-outfit.blend` в Blender 4.3 или новее.
   Выбрать `OutfitControls` → Object Properties → Custom Properties:
   `cap_head`, `glasses`, `backpack`. Эти параметры управляют видимостью и CapOn.
4. Для смены тестового движения выбрать `SprigHeroRig`, открыть Dope Sheet →
   Action Editor и выбрать `Study_Idle`, `Study_Look`, `Study_Step`, `Study_Joy`.
   Частота — 24 кадра/с, длина 73 кадра, у Step — 49. Space запускает воспроизведение.

GLB хранит детали отдельно и сохраняет CapOn, но не исполняет Blender-драйверы.
Переключение в HTML задано явно: значение морфа и видимость кепки меняются вместе.

## Важная находка в исходной анимации

Четыре action из `SprigHero@Anims.fbx` имеют названия Idle, Wave, Walk, Joy и по
259 кривых, но **ни одна кривая не меняется между ключами** с допуском 1e-6.
Названия и длительности экспортировались, движение в данном файле отсутствует.
Все четыре сохранены в `.blend` как `Source_*`; это не готовые движущиеся клипы.

Чтобы проверить крепления в движении, отдельно созданы четыре **Study_***:
дыхание/лёгкий наклон, повороты головы, шаги на месте, два радостных подскока.
Это проверочные движения, не восстановление потерянных исходных анимаций и не
утверждённая библиотека для релиза. Мимика остаётся исходной текстурой.

## Проверка и ограничения

- Сравнены имена, иерархии и матрицы покоя всех присланных скелетов.
- Хеши координат, UV и весов каждого меша до/после сборки совпадают.
- Проверены все восемь сочетаний экипировки и реальные события переключателей HTML.
- Проверены изменения геометрии на четырёх новых движениях.
- GLB повторно импортирован в Blender: сравнение всех вершин с исходной сборкой
  в 12 позах, максимальная ошибка около 0.000018 при высоте героя 2.
- Просмотрщик проверен в Chromium с документом, поданным через локальный HTTP:
  управляемый браузер облака блокирует переходы file://. Сам HTML не изменялся;
  прямое открытие файла на Windows в этой среде не проверялось.
- Полная проверка отсутствия пересечений во всех возможных позах и подготовка
  мобильных слоёв ещё не выполнены. На устройство 3D-модель не добавлялась.

Игра использует пререндеренные 2D-кадры. Этот офлайн-пример не меняет Home, магазин,
профиль, старый Hero Lab или APK. Сетки остаются высокой плотности из исходников;
оптимизация и подготовка слоёв — отдельный следующий этап после оценки примера.

## Воспроизведение

```sh
blender -b --factory-startup -t 4 --python-exit-code 1 --python tools/heroanim/sprig-outfit-study.py -- --source-dir path/to/five-fbxs --out content/work/sprig-outfit-study/build
blender -b --factory-startup -t 4 --python-exit-code 1 --python tools/heroanim/validate-sprig-outfit.py -- --out content/work/sprig-outfit-study/build
node tools/heroanim/review-sprig-outfit.mjs content/work/sprig-outfit-study/build
```

Node использует существующие зависимости `tools/heroanim` (Three.js r160 и Playwright).
`HERO_ANIM_CHROMIUM` выбирает установленный Chromium. Исходники, права и контрольные
суммы — `source-inputs.json` и `tools/heroanim/SOURCE.md`; отчёты — рядом с этим файлом.
